# Thai 24-Key Compact Keyboard for Android (แป้นพิมพ์ภาษาไทย 24 ปุ่ม)

แอปพลิเคชันคีย์บอร์ดภาษาไทยบน Android สไตล์ **24 ปุ่ม** พร้อมระบบ **Multi-tap / Double-tap** สำหรับพิมพ์ตัวอักษรบนโดยไม่ต้องกดปุ่ม Shift

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **เลย์เอาต์ภาษาไทย 24 ปุ่ม (3 แถว x 8 ปุ่ม)**:
   - ลดจำนวนปุ่มลงเหลือ 24 ปุ่ม ช่วยให้ปุ่มมีขนาดใหญ่ขึ้น ลดปัญหานิ้วเบียด พิมพ์ด้วยนิ้วโป้งมือเดียวได้สะดวก
   - รวมพยัญชนะไทยครบทั้ง 44 ตัว พร้อมสระ วรรณยุกต์ และเครื่องหมายสำคัญ
2. **ระบบกดซ้ำเพื่อพิมพ์ตัวบน (Multi-tap / Double-tap Engine)**:
   - **แตะ 1 ครั้ง**: พิมพ์ตัวอักษรหลัก (ตัวล่าง)
   - **แตะซ้ำ 2 ครั้งทันที (ภายใน 380ms)**: ลบตัวแรกและเปลี่ยนเป็นตัวอักษรบนอัตโนมัติ (ไม่ต้องเอื้อมนิ้วไปกดปุ่ม Shift)
   - **แตะซ้ำ 3-4 ครั้ง**: สลับไปยังตัวอักษรเสริม / ตัวหายาก
   - **กดค้าง (Long-press)**: ทางเลือกเสริม สามารถกดค้างเพื่อพิมพ์ตัวบนได้ทันที
3. **ดีไซน์ปุ่มแบบ Dual/Triple Preview**:
   - แต่ละปุ่มจะแสดงตัวอักษรหลักตรงกลาง (ขนาดใหญ่)
   - แสดงตัวอักษรบนที่มุมขวาบน (สีน้ำเงินไฮไลต์) ให้เห็นชัดเจนว่ากดซ้ำแล้วจะได้ตัวอะไร
4. **โหมดอื่นๆ ครบครัน**:
   - สลับแป้นภาษาอังกฤษ (English QWERTY)
   - สลับแป้นตัวเลขและสัญลักษณ์ (?123)
   - ระบบสั่นสัมผัส (Haptic Feedback) ทุกครั้งที่กด
5. **หน้าจอ Setup Onboarding ในแอป**:
   - กดเปิดใช้งานคีย์บอร์ดในการตั้งค่า Android ได้ในคลิกเดียว
   - ช่องทดสอบพิมพ์ภายในแอปทันที

## 🚀 วิธีเปิดและติดตั้งใน Android Studio

1. **เปิดโปรเจกต์**:
   - เปิดโปรแกรม **Android Studio**
   - เลือก **Open** แล้วเปิดโฟลเดอร์:
     `C:\Users\golf9\.gemini\antigravity\scratch\Thai24Keyboard`
2. **รอ Gradle Sync**:
   - Android Studio จะทำการดาวน์โหลด Dependencies และซิงก์โปรเจกต์ให้โดยอัตโนมัติ
3. **รันบนโทรศัพท์จริงหรือ Emulator**:
   - ต่อสาย USB กับสมาร์ตโฟน Android (เปิด USB Debugging) หรือเปิด Android Emulator
   - กดปุ่ม **Run (▶)** สีเขียวใน Android Studio
4. **เปิดใช้งานคีย์บอร์ดในเครื่อง**:
   - เมื่อแอปเปิดขึ้นมา แตะปุ่ม **"ไปที่การตั้งค่าแป้นพิมพ์"** (Step 1) เพื่อเปิดสวิตช์อนุญาตใช้งาน
   - แตะปุ่ม **"เลือกวิธีป้อนข้อมูล"** (Step 2) แล้วเลือก **"แป้นพิมพ์ไทย 24 ปุ่ม"**
   - ทดลองพิมพ์ในกล่องทดสอบได้ทันที!
